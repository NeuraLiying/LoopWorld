# 布局错误专项训练（v3）设计短注 · 2026-10-15

## 针对的问题
SF 评测（`maze_sf_eval_20261015.md`）显示主要失败是：转弯处或首访时，该出现墙的地方模型生成了走廊，这段错误几何随后被写进记忆、在回访时被复现。

## 改动（全部为新文件：`loopworld/layout_utils.py`、`scripts/run_maze_v3_layout_train.py`、`scripts/maze_v3_eval.py`；旧脚本未改）
1. **难帧过采样 + 加权**
   - 难帧定义：画面中心 1/3 区域的 GT 深度中位数 < 1.2 m（正对墙），或者在岔路口（度 ≥3 的 cell）发生转弯。约占 46% 的帧；最初的定义（含全部转弯和岔路口）占 66%，太宽，已收窄。
   - 槽位重置时，以 50% 概率从某个难帧之前 1–5 帧开始。
   - 难帧的损失权重 ×3（按 batch 均值归一化），由新的 `weighted_train_step` 实现。
2. **置信度记忆**
   - rollout 时用两组噪声各采样一次（S3 R4，合并成 2B 一次前向）。
   - 只有两次采样一致的像素（RGB 最大差 < 0.08、深度相对差 < 5%、两次都是有效表面）才积分进记忆。实测约 77–84% 的像素被接受。
   - 评测 `own_conf` 模式使用同一规则。
   - **偏差**："旧低置信点衰减"没有实现。点云不存置信度，目前只靠"不写入"来过滤。
3. **更慢的课程**：p_own 在 12000 步内从 0.5 升到 0.85（SF 是 6000 步内从 0.2 升到 0.8）。
4. **深度指标**：新增 AbsRel 中位数、δ<1.25、墙（命中）mask IoU、开阔（天空）mask IoU。
