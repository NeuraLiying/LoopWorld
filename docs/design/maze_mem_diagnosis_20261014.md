## 解读
1. **结论：主要差距来自训练/测试不匹配，即误差在记忆里自我累积（b ≫ a）。容量或分辨率不是主要瓶颈。**
   - 记忆换成 GT 以后，AR 从 17.5 升到 28.6（+11 dB），回访 vs GT 从 17.0 升到 33.3（+16 dB），AbsRel 从 0.52 降到 0.08。上一帧仍是模型自己的预测。
   - 也就是说，模型已经学会利用正确的记忆，而且利用得很充分。真正的问题在于：测试时写进记忆的是它自己略有错误的预测（提示 PSNR 只有 17.8，GT 积分是 26.5）。训练时它只见过 GT 积分出的干净记忆，没见过这种"脏记忆"，于是误差一路累积。
2. **有记忆比无记忆好**：(a) 比 (d) 高 +2.4 dB，回访 vs GT 高 +3 dB。说明即使是"脏记忆"也有用，模型没有忽略 slot0。
3. **上一帧同样重要**：(c) 比 (b) 再高 +7 dB，主要提升在 9-32 段（22.0 → 34.2）。这一段记忆覆盖还低，模型更依赖上一帧。所以 AR 的短程漂移也要处理。
4. **记忆本身也有上限**：用 GT 积分时，覆盖区内的提示 PSNR 只有 26.5，回访帧覆盖率约 55%。原因：最近邻取整 splat 没有补洞、12 万点上限、时序 stride 4。这是次要瓶颈，可以靠更好的 splat（2×2 或深度检验 + 补洞）、提高点数上限来改善。
5. **"回访 vs 自身首访"高、"vs GT"低的情况**：(a) 是 24.1 vs 17.0，表示模型一致地复现自己之前的错误。(b) 里自洽仍是 24.3，因为它的首访帧在记忆不全时生成，本身就不准；回访时有了 GT 记忆就更准了，所以和首访不一致。

## 建议的下一步（待批准）
- **首选：缓解训练/测试不匹配**，即训练时向记忆里注入"像预测一样的误差"。可选做法：
  - 记忆积分时混入模型自己的预测：训练中先用 EMA 模型做几步快速采样，再把结果积分进记忆，类似 scheduled sampling / self-forcing；
  - 或者低成本近似：对 GT 积分的记忆加颜色和深度噪声、模糊、随机丢点；
  - 上一帧也同样做加噪，或替换为模型自己的预测。
- 次要：改进 splat 质量和覆盖率，即 2×2 splat、补洞、提高点数上限。
